## 🛠️ Tecnologías y Características Principales

* **Plataforma:** Android Nativo (Kotlin).
* **Autenticación:** Firebase Authentication (Correo/Contraseña e inicio de sesión rápido con Google).
* **Persistencia NoSQL:** Firebase Firestore (Gestión de colecciones para usuarios, favoritos y listas personalizadas).
* **Consumo de API REST:** Retrofit 2 (Obtención de catálogos cinematográficos y tráilers en tiempo real).
* **Interfaz de Usuario:** Material Design, RecyclerViews dinámicos y soporte de navegación inferior (*BottomNavigationView*).
